# Data folder

Stores the transaction datasets used for model training and batch analysis.

- `synthetic_transactions.csv` - SYNTHETIC demonstration dataset
  (6,000 rows, ~4% fraud rate). Generated deterministically by
  `python -m ml.generate_synthetic_data` (see `backend/ml/`).
  It contains NO real customer records, no PII, no card numbers.
- `model_metrics.json` - genuine training/evaluation metrics
  produced by `python -m ml.train_model` (served by the
  Model Performance page). Regenerated on every training run.
- `evaluation/` - confusion matrix and precision-recall plots
  generated by the training script.
- The dataset schema is inspected BEFORE any preprocessing code
  is written (`python -m ml.inspect_dataset`).
- Never place PII, card numbers, account credentials, or confidential data here.
