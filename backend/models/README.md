# Models folder

Stores fitted machine-learning artifacts saved with joblib by the training script (Phase 6):

- Random Forest classifier
- XGBoost classifier
- (Optional) Isolation Forest anomaly detector
- Fitted preprocessing objects (scalers, encoders, feature list)

These files are generated by the training script and are git-ignored because they
are large and reproducible. `GET /api/model/status` reports whether the artifacts
are present, and prediction endpoints fail gracefully when they are missing.
